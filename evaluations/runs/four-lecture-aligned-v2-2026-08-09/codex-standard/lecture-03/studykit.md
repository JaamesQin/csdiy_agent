# Lecture 3：逼近理论、宽度与深度

建议学习时间：180 分钟

## 学习目标

- 区分逼近、优化与泛化，并把本讲结论定位为表达存在性结论。
- 从 Lipschitz 约束推导一维矩形条及 d 维超矩形的积分误差。
- 拆解用 ReLU 近似一维矩形、d 维超矩形与任意 Lipschitz 曲面的三层构造。
- 利用分段线性与 kink 计数比较宽度、深度对表达复杂度的影响。
- 复现三角形函数自复合的深度分离，并陈述其对训练与泛化不作保证。

## 核心概念

### 逼近、优化、泛化

逼近问模型族中是否存在拟合函数，优化问能否找到它，泛化问未见数据上是否有效；本讲集中于逼近。

### L-Lipschitz 条件

函数输出变化的绝对值不超过输入变化的 L 倍；多维输入使用 RMS 范数。

### RMS 范数

RMS 范数等于各坐标平方平均的平方根，表示向量坐标的平均尺度。

### 三层 ReLU 逼近定理

单位 d 维超立方体上的任意 L-Lipschitz 函数，对任意 ε>0，存在规模为 4d(L/ε)^d 的三层 ReLU 网络，使积分 L1 误差小于 2ε。

### 一维分片矩形误差

N 条等宽区间中，每条的最大偏差形成底 1/N、高 L/N 的三角形；总面积不超过 L/(2N)，故 N=L/(2ε) 足以达到 ε。

### 高维矩形逼近

N 个超矩形边长 N^{-1/d}，误差帽高度 L/N^{1/d}，合计误差不超过 L/N^{1/d}；达到 ε 需 N=(L/ε)^d。

### 一维 ReLU 矩形

四个带平移的 ReLU 按 +1,-1,-1,+1 线性组合，在 c→∞ 时逼近 [0,1] 的矩形指示；权重和偏置可平移矩形。

### 超矩形门与线性组合

各坐标的一维矩形全部开启时，和才超过 d−1；在该阈值施加 ReLU 得到超矩形，再用带位置参数的超矩形线性组合逼近曲面。

### 维数灾难与训练局限

构造需要对维数指数增长的神经元；矩形表示若只落在训练点上并被权重衰减抑制其他部分，可能不泛化。

### 普适逼近的非充分性

Fourier 级数、多项式和 Python 程序空间也具有广泛表达能力，但这不意味着通常用它们完成机器学习；普适逼近不足以保证学习成功。

### ReLU 网络的分段线性性

ReLU 本身分段线性，分段线性函数对和、复合、标量乘法封闭，因此 ReLU 网络可用梯度改变处 kink 的数量分析。

### kink 递推界

宽度 n 的线性组合至多累加 kinks，ReLU 至多将线性片段一分为二，所以 KINKS_l≤2n KINKS_{l−1}，从 KINKS_0=1 得 KINKS_L≤(2n)^L。

### 三角形函数复合

宽度 2 的三角形 ReLU 函数每次与自身复合使线性区域数翻倍。

### 深度分离数值例

g 自复合 500 次有 2^500−1 个 kinks，以 1000 层、宽度 2 表示；若换成三层网络，匹配该 kink 数需约 7×10^49 宽度。

### 逼近结论的实践边界

深度分离不意味着深网络容易训练或泛化良好；寻找实际最优宽深比还会受学习率等训练管线混杂因素影响。
