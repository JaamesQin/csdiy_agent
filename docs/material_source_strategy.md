# 模板课程与用户资料双入口方案

更新日期：2026-08-02  
状态：已确定为产品与实施计划

## 决策

CoursePilot 同时支持：

1. 多个经过审核的模板课程；
2. 项目未预先收录的用户私有资料；
3. 用户明确确认后的模板资料与私有资料混合模式。

三种模式共享同一套解析、分块、索引、引用、StudyKit、答疑、代码辅导和复盘管线。模板课程使用公共 CourseManifest；未收录资料使用私有 MaterialManifest；运行时统一映射为 MaterialSet。

## 模板课程路径

```text
了解学习目标
→ 推荐 2–3 门模板课程
→ 展示课程版本、理由、先修、官方课程页和整课下载页
→ 展示 CoursePilot 已支持讲次及单讲官方资源页
→ 用户选择讲次
→ 复用已有索引或触发按讲解析
→ StudyKit / 答疑 / 代码辅导 / 复盘
```

模板课程按三级管理：

- `catalog`：可推荐，具有经过核验的官方课程页和下载入口；
- `supported`：部分讲次完成来源审核，可按需解析；
- `demo`：具有核心讲次、黄金 StudyKit 和固定评测。

CoursePilot 提供官方链接，不重新分发整套课程资料。

## 未收录用户资料路径

```text
用户提供文件 URL、公开链接、文本或通过可用上传入口提供资料
→ 安全与可解析性检查
→ 尝试识别课程、版本和讲次
→ 必要时请用户确认；无法识别则保持 unknown
→ 建立私有 MaterialManifest/MaterialSet
→ 解析并建立私有索引
→ 使用文件名和页码/标题引用
→ 按保留策略删除
```

课程识别、模板匹配和文件可解析性必须分开判断。资料没有被预先收录、没有课程名称或无法确认版本，都不能成为拒绝解析的理由。

匹配状态：

- `exact`：checksum 或经过核验的版本证据完全一致，可以复用公共解析结果；
- `possible`：可能匹配，必须由用户确认后才能与模板资料合并；
- `none`：不匹配模板，直接作为私有未知资料处理。

## 混合模式

只有用户明确选择“同时使用两者”后，检索范围才能包含公共模板和私有资料。发生冲突时并列展示来源，不静默覆盖：

```text
[官方模板｜课程、讲次、页码]
[用户上传｜文件名、页码]
[教学补充]
```

用户可以选择只使用官方资料、只使用上传资料或同时使用并标明来源。

## 权限和存储

```text
公共模板索引：data/indexes/public/<course_id>/<unit_id>/
私有运行时索引：<private_store>/<owner_id>/<material_set_id>/
```

私有原文、派生片段和索引不得写入源码仓库。检索必须先按 `owner_id / session_id / material_set_id` 授权过滤；不能依靠向量相似度实现隔离。

## 平台边界

清小搭原生 `file` 输入只有在账号实测通过后才能对外声明可用。其未开放时：

- 模板课程完整路径不受阻塞；
- 未收录资料管线通过公开链接、文本粘贴或自研测试入口实现和验收；
- 不得把降级入口描述为清小搭原生上传能力。

## 首轮验收

1. MIT 6.7960 作为首个 `demo` 模板课程，支持推荐、官方下载链接和 Lecture 1、2、4、8、9。
2. Lecture 2 和 Lecture 8 为核心 Demo。
3. 一份未预先收录、课程身份未知的 PDF 能建立私有 MaterialManifest 并生成带文件名/页码引用的 StudyKit。
4. 未经确认，私有资料不与 MIT 6.7960 混合。
5. 两个用户或会话不能检索到彼此的私有资料。
