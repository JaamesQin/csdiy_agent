# Virtual memory for applications

> 课程：mit-6.s081-fall-2021 · 版本：fall-2021 · 单元：lecture-17

## 学习目标

- 能够说明 mmap、mprotect、munmap、sigaction 和 VMA 在用户级 VM 中的角色。
- 能够画出一次用户页故障从 CPU 到处理器再恢复指令的完整路径。
- 能够解释虚拟内存如何支持按需数据结构和并发垃圾回收。
- 能够比较 VM 页故障方案与编译器插入显式检查的成本和工程边界。
- 能够区分讲义对 1991 年论文结果的转述与可泛化的接口设计原则。

## 前置知识

- 页表与页故障：理解保护位、缺页陷入和重新执行故障指令。
- UNIX 进程信号：知道内核可把异常转换为用户态信号处理器调用。
- 垃圾回收：理解根集合、可达对象、复制收集和 mutator/collector 的区别。

## 核心概念

### VMA

VMA 描述一段连续虚拟地址的权限和后备对象，内核据此决定页故障应调页、发信号还是终止。

来源：mit-6.s081-f21-lecture-17-material@page:1

### 用户态页故障 upcall

内核保存用户状态并通知用户处理器；处理器修复页面权限后返回，内核再恢复或重启故障指令。

来源：mit-6.s081-f21-lecture-17-material@page:1, mit-6.s081-f21-lecture-17-material@page:2

### 用户级 VM 原语

保护、解除保护、脏页查询和别名映射等原语让应用把硬件页机制用于 GC、checkpoint 和按需数据。

来源：mit-6.s081-f21-lecture-17-material@page:1

### Baker 复制式并发 GC

对象从 from-space 复制到 to-space，以转发指针连接旧位置和新副本，并逐步扫描未扫描区域。

来源：mit-6.s081-f21-lecture-17-material@page:2

### 页故障作为读屏障

把未扫描区域设为不可访问，应用首次触碰页面时由处理器扫描该页并解除保护，从而避免每次解引用的显式测试。

来源：mit-6.s081-f21-lecture-17-material@page:2

### 机制与性能权衡

VM 方案减少编译器插桩但要求高效陷入与 OS 支持；故障频率、页面扫描时间和抽象开销决定收益。

来源：mit-6.s081-f21-lecture-17-material@page:3

## 学习顺序

1. 复习页表、页故障、信号与复制式 GC。（20 分钟）
2. 学习用户级 VM 原语和现代 UNIX 接口。（30 分钟）
3. 追踪 VMA 决策与用户态页故障 upcall。（30 分钟）
4. 推导按需虚拟表和 Baker 并发 GC。（40 分钟）
5. 分析页保护读屏障及其同步边界。（30 分钟）
6. 完成 VM 与显式检查的综合权衡评估。（30 分钟）

## 练习

### p1 · 基础

为文件映射、匿名堆区、只读保护和移除映射四个需求分别选择 mmap/mprotect/munmap，并写出关键权限意图。

提示：不要求记完整参数，只需接口与目标匹配。

提交：需求到接口映射表。

来源：mit-6.s081-f21-lecture-17-material@page:1

### p2 · 流程

画出一次访问受保护页面的路径：CPU、内核、VMA、信号处理器、mprotect、指令恢复。

提示：处理器必须避免重复故障。

提交：带状态变化的时序图。

来源：mit-6.s081-f21-lecture-17-material@page:1, mit-6.s081-f21-lecture-17-material@page:2

### p3 · 应用

设计一个逻辑上很大的按需平方根表，仅用一个物理页缓存当前数据；说明索引访问、故障、填充和替换步骤。

提示：把逻辑地址空间与实际驻留页分开。

提交：状态机与缓存失效说明。

来源：mit-6.s081-f21-lecture-17-material@page:2

### p4 · 推理

用 from-space/to-space 图解释 VM 页保护怎样替代每次指针解引用检查，并指出仍需同步的竞态。

提示：跟踪一个应用线程和一个收集器线程同时触碰同一未扫描页。

提交：对象图、页面状态和同步点。

来源：mit-6.s081-f21-lecture-17-material@page:2

### p5 · 综合评价

比较“编译器插入每次引用检查”和“不可访问页触发处理器”两种 GC 设计，列出性能、编译器改动、OS 支持和可移植性权衡。

提示：不要只比较单次成本，还要考虑每页最多一次故障和并行扫描。

提交：多维决策表和适用条件。

来源：mit-6.s081-f21-lecture-17-material@page:2, mit-6.s081-f21-lecture-17-material@page:3
