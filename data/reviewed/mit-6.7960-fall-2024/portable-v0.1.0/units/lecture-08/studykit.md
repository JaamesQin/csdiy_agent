# Lecture 8：Transformers

> 课程：mit-6.7960-fall-2024 · 版本：fall-2024 · 单元：lecture-08

## 学习目标

- 把输入表示为 N×d 的 token 矩阵，并解释 token 与标量神经元表示的区别。
- 分别写出跨 token 线性混合与共享逐 token 非线性，辨认两者作用的轴。
- 从 token 矩阵推导 Q、K、V、缩放点积注意力矩阵及输出的形状。
- 说明多头注意力如何并行、拼接和投影，并读懂 Transformer/ViT 块中的归一化、MLP 与残差。
- 准确区分置换等变性与置换不变性，并用等式检验 Transformer 的置换行为。
- 从置换等变性说明加入位置信息的必要性，并把 Fourier 编码视为课件给出的一个示例。
- 解释自回归下一 token 预测中因果掩码的作用，并审计多层网络是否保持时间方向。
- 沿已审计的模块标签说明图像编码器、文本解码器与跨注意力之间的数据流。

## 前置知识

- 线性代数与矩阵形状：能进行矩阵乘法、转置和按行线性组合，并能追踪 N×d 表示的形状。
- 神经网络基础：理解线性变换、逐元素或逐表示非线性、残差连接与归一化的基本角色。
- softmax 与序列预测：能读取 softmax 矩阵表达式，并理解用前缀预测下一个 token 的任务表述。

## 核心概念

### token 与 N×d 矩阵

课件把 token 定义为神经元向量，并用 N 行、每行 d 维的矩阵组织一组 token。图像可以先分块，再把每个块投影成一个 token；这里仅保留课件可见的抽象步骤，不复刻示例图像细节。

来源：mit6-7960-f24-lec8-e72290651c@page:11, mit6-7960-f24-lec8-e72290651c@page:14, mit6-7960-f24-lec8-e72290651c@page:16

公式：$$T_{\mathrm{in}}\in\mathbb{R}^{N\times d}$$

### 跨 token 线性混合

输出的第 i 个 token 是所有输入 token 的加权和；把权重 w_ij 排成矩阵 W 后，混合写成左乘 WT_in。这个操作改变 token 之间的信息组合，而不把通道维 d 当作被求和的 token 轴。

来源：mit6-7960-f24-lec8-e72290651c@page:17

公式：$$T_{\mathrm{out}}[i,:]=\sum_{j=1}^{N}w_{ij}T_{\mathrm{in}}[j,:],\quad T_{\mathrm{out}}=WT_{\mathrm{in}}$$

### 共享逐 token 非线性

同一个函数 F_θ 独立地应用到每一行 token。它与跨 token 混合互补：前者逐 token 修改表示，后者在 token 之间交换信息。

来源：mit6-7960-f24-lec8-e72290651c@page:18

公式：$$T_{\mathrm{out}}=\begin{bmatrix}F_\theta(T_{\mathrm{in}}[0,:])\\\vdots\\F_\theta(T_{\mathrm{in}}[N-1,:])\end{bmatrix}$$

### 由数据生成的注意力权重

Transformer 可从全连接 token 图的视角理解；注意力不使用固定的 token 混合矩阵，而是根据当前输入生成连接权重。由此，混合模式可随输入改变。

来源：mit6-7960-f24-lec8-e72290651c@page:24, mit6-7960-f24-lec8-e72290651c@page:26

### Q/K/V 与缩放点积自注意力

同一 token 矩阵 T 分别线性投影为 query、key 和 value。QKᵀ 产生 token 两两之间的分数，除以 √m 后按课件公式做 softmax 得到 A，再由 AV 汇聚 value。这里沿用已审计公式，不把第 39 页示意代码的轴写法扩展为通用实现规范。

来源：mit6-7960-f24-lec8-e72290651c@page:34

公式：$$Q=T W_q^\top,\ K=T W_k^\top,\ V=T W_v^\top,\ A=\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt m}\right),\ T_{\mathrm{out}}=AV$$

### 多头自注意力

k 个注意力头并行处理同一输入，各自得到输出；这些输出先拼接为中间表示，再乘 W_MSA 投影。候选稿不补造课件未显示的具体头数或额外维度。

来源：mit6-7960-f24-lec8-e72290651c@page:37

公式：$$T_{\mathrm{out}}^{i}=\operatorname{attn}^{i}(T_{\mathrm{in}}),\ i\in\{1,\ldots,k\};\quad T_{\mathrm{out}}=\bar T_{\mathrm{out}}W_{\mathrm{MSA}}$$

### Transformer/ViT 块

课件的 ViT 块把多头自注意力、token norm、逐 token MLP 和残差连接组织成可重复的块。学习时应分别标注跨 token 的注意力路径与逐 token 的 MLP 路径，而不从结构示意补造训练目标。

来源：mit6-7960-f24-lec8-e72290651c@page:38

### 置换等变性

如果先置换 token 再经过 Transformer，结果等于先经过 Transformer 再对输出做同样置换。这是等变性：输出会随输入一同重排，并不是所有排列都产生同一个不变输出。

来源：mit6-7960-f24-lec8-e72290651c@page:35, mit6-7960-f24-lec8-e72290651c@page:41

公式：$$\operatorname{transformer}(\operatorname{permute}(T))=\operatorname{permute}(\operatorname{transformer}(T))$$

### 位置编码

当任务需要 token 的位置或顺序时，可向 token 加入位置信息，以打破纯内容处理无法区分位置的局限。课件展示 Fourier 位置码作为一种示例，但并未把它规定为唯一方案。

来源：mit6-7960-f24-lec8-e72290651c@page:43, mit6-7960-f24-lec8-e72290651c@page:44

### 自回归、因果注意力与跨注意力

自回归模型按已有前缀预测下一个 token；训练时的因果注意力掩码阻止位置读取未来 token，多层堆叠仍须保持这一时间方向。课件还以已标注的图像编码器、自动回归文本解码器和跨注意力说明跨模态模块之间的数据流；这里只保留这些模块关系。

来源：mit6-7960-f24-lec8-e72290651c@page:48, mit6-7960-f24-lec8-e72290651c@page:51, mit6-7960-f24-lec8-e72290651c@page:52, mit6-7960-f24-lec8-e72290651c@page:54

## 学习顺序

1. 阅读讲座范围、token 定义与图像分块抽象，建立自己的符号表。（20 分钟）
2. 完成 token 矩阵、跨 token 混合与逐 token 非线性的形状练习。（25 分钟）
3. 从数据依赖的混合视角推导 Q/K/V、注意力矩阵 A 与输出形状。（30 分钟）
4. 标注多头注意力的并行、拼接、投影，并拆解 ViT 块的数据路径。（25 分钟）
5. 用具体置换检验等变等式，并纠正“等变就是不变”的误解。（20 分钟）
6. 说明为何加入位置信息，并比较一般位置编码需求与 Fourier 示例的证据范围。（15 分钟）
7. 绘制自回归依赖表，逐层审计因果掩码是否允许未来信息泄漏。（25 分钟）
8. 依据可见模块标签重画图像编码器—文本解码器—跨注意力数据流，并完成总复盘。（20 分钟）

## 练习

### p-01 · 基础

设有 N 个 token、每个 token 含 d 个通道。写出输入矩阵的形状，标出一行和一列各代表什么，并说明图像分块后怎样进入这个表示。

提示：先固定“行是 token、列是通道”，只描述分块与投影的抽象流程。

提交：一张带行列标签的 N×d 矩阵草图和三句说明。

来源：mit6-7960-f24-lec8-e72290651c@page:14, mit6-7960-f24-lec8-e72290651c@page:16

### p-02 · 基础计算

给定一个 3×d 的 token 矩阵和自选的 2×3 权重矩阵 W，逐行计算 WT_in，并解释求和发生在哪个轴；再写出逐 token 函数 F_θ 的输出形式。

提示：把 W 的一行当作对三个输入 token 的权重；F_θ 则对每一行独立复用。

提交：矩阵乘法、两个输出 token 和一段两类操作的比较。

来源：mit6-7960-f24-lec8-e72290651c@page:17, mit6-7960-f24-lec8-e72290651c@page:18

### p-03 · 核心推导

令 T 为 N×d，并为 W_q、W_k、W_v 自选与公式相容的投影形状。推导 Q、K、V、QKᵀ、A 和 AV 的形状，说明 A 的两个 N 轴分别索引什么。

提示：先令 query/key 投影维数为 m；保证 Q 与 K 的内积维相同，再处理 value 维。

提交：一条完整形状链和对 A 行列语义的说明。

来源：mit6-7960-f24-lec8-e72290651c@page:34

### p-04 · 核心架构

画出 k 个注意力头处理同一 T_in 的数据流：分别标出并行输出、拼接结果和 W_MSA 投影；随后把该模块放进包含 token norm、MLP 和残差的 ViT 块。

提示：先画单层的扇出—拼接—投影，再区分注意力路径和逐 token MLP 路径。

提交：一幅仅含模块与张量标签的架构图，以及每个模块的一句作用说明。

来源：mit6-7960-f24-lec8-e72290651c@page:37, mit6-7960-f24-lec8-e72290651c@page:38

### p-05 · 核心辨析

选择三个 token 和一个非平凡置换 P，用符号写出 Transformer(P(T)) 与 P(Transformer(T)) 的对应关系；再构造一句错误的“不变性”表述并纠正它。

提示：等变要求输出顺序随输入一起变；不变则要求输出完全相同。

提交：一个置换示例、一条等变等式和一组错误—纠正对照。

来源：mit6-7960-f24-lec8-e72290651c@page:35, mit6-7960-f24-lec8-e72290651c@page:41

提示：论证顺序应是“对称性—任务需要—加入信息—示例边界”。

提交：四段式设计说明和一条证据范围声明。
